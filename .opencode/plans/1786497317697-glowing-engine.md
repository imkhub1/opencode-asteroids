# Plan: Comando local para crear worktrees

## Alcance

Crear un comando personalizado de proyecto llamado `/worktree`, disponible solo en este repositorio, que reciba el argumento completo aunque contenga espacios y ejecute únicamente la creación del worktree.

## Cambios

1. Crear `.opencode/commands/worktree.md` con una descripción breve y `agent: build` para que el comando pueda ejecutar Git independientemente del modo activo.
2. Usar `$ARGUMENTS` para capturar todo el texto introducido después de `/worktree`.
3. Indicar que el argumento se trate solo como datos y se transforme en un slug: recortar espacios exteriores, convertir a minúsculas, reemplazar secuencias de espacios por guiones, eliminar caracteres fuera de `a-z`, `0-9` y `-`, colapsar guiones y eliminar guiones al inicio y al final.
4. Si el slug queda vacío, no ejecutar nada. En otro caso, ejecutar desde el directorio actual exactamente:

   `git worktree add .worktrees/<slug>`

5. Prohibir explícitamente `cd`, `mkdir`, comprobaciones como `git status`, opciones o argumentos adicionales, wrappers, interpolación shell y cualquier comando distinto del anterior.

## Verificación

1. Confirmar que el archivo está en `.opencode/commands/` y que su frontmatter no contiene `template`.
2. Reiniciar OpenCode si el comando no aparece automáticamente.
3. Probar `/worktree "Nueva pantalla de login"` y comprobar que el único comando solicitado sea `git worktree add .worktrees/nueva-pantalla-de-login`.
4. Probar también un argumento sin espacios y uno que produzca un slug vacío, verificando que el último no ejecute comandos.
